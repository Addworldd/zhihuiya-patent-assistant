# 智慧芽 (PatSnap) 检索式语法速查表

当用户提出带有时间范围、特定申请人、发明人、IPC/CPC 分类号或特定字段限定的复杂查询时，使用本速查表构造 `--raw-query` 参数（或直接传给 `search_patents` 的 `query_text`）。

## 1. 常用字段检索符

| 字段代码 | 含义 | 示例 |
| :--- | :--- | :--- |
| `TAC:(...)` | 标题 + 摘要 + 权利要求（最常用主题检索） | `TAC:(固态电池 AND 硫化物)` |
| `TI:(...)` | 专利标题 | `TI:(折叠屏)` |
| `AB:(...)` | 专利摘要 | `AB:(激光雷达)` |
| `CLMS:(...)` | 权利要求书 | `CLMS:(碳纳米管)` |
| `ANCS:(...)` | **智慧芽公司树当前权利人**（自动包含集团母公司、控股子公司、外文及曾用名主体） | `ANCS:(华为)`、`ANCS:(比亚迪)` |
| `ANS:(...)` | **智慧芽公司树原始申请人**（自动包含集团母公司、控股子公司、外文及曾用名主体） | `ANS:(宁德时代)` |
| `ANC:(...)` | 当前权利人 + 原始申请人（字面匹配） | `ANC:(华为 OR Huawei)` |
| `AN:(...)` | 原始申请人（字面匹配） | `AN:(宁德时代)` |
| `IN:(...)` | 发明人姓名 | `IN:(王传福)` |
| `PN:(...)` | 公开（公告）号 | `PN:(CN110806829B)` |
| `APNO:(...)` | 申请号 | `APNO:(CN201910838420)` |
| `IPC:(...)` | IPC 国际专利分类号 | `IPC:(H01M10/0525)` |
| `CPC:(...)` | CPC 联合专利分类号 | `CPC:(G06F3/048)` |
| `APD:[起始 TO 结束]` | 申请日范围（格式 `YYYYMMDD` 或 `YYYY`） | `APD:[20230101 TO 20261231]` |
| `PBD:[起始 TO 结束]` | 公开/公告日范围 | `PBD:[20240101 TO 20261231]` |
| `PNC:(...)` | 受理局/公开国家代码 | `PNC:(CN OR US OR EP OR WO)` |

## 2. 逻辑运算符与通配符

- `AND`：同时包含（如 `ANC:(小米) AND TAC:(影像 OR 摄像头)`）
- `OR`：包含任意一个（同义词扩展，如 `TAC:(无人机 OR 无人驾驶飞行器 OR UAV)`）
- `NOT`：排除特定词（如 `TAC:(电池) NOT TAC:(铅酸)`）
- `*`：多字符通配符（如 `electr*`）

## 3. 客户面谈常见场景检索式模板

1. **查某公司在某产品/领域的专利**：
   ```text
   ANC:(公司全称 OR 公司简称) AND TAC:(产品关键词1 OR 同义词2)
   ```
2. **查某公司近两年的最新研发动向**：
   ```text
   ANC:(公司简称) AND APD:[20240101 TO 20261231]
   ```
3. **查某技术细分赛道并限定中国授权专利**：
   ```text
   TAC:(核心技术词) AND PNC:(CN)
   ```
