# 智慧芽 (PatSnap) 移动端专利速查与精读助手 (`zhihuiya-patent-assistant`)

专为 **WorkBuddy** 客户端（支持手机端远程访问与面谈速查）设计的智慧芽专利全景检索与单篇深度精读 Skill。

---

## ✨ 核心特性

- **零环境门槛（自动安装 Python）**：同事电脑无需预先安装 Python 或配置 MCP，首次调用时内置自举启动器（`scripts/run_helper.ps1` / `run_helper.sh`）会自动静默部署 10MB 免安装绿色版 Python 3.11。
- **主体/领域专利概览 (`overview`)**：
  - 内置**正交要素拆分与中英文同义扩展 SOP**，高查准率、不跑偏；
  - 基于智慧芽公司树（`ANCS/ANS`）自动穿透识别**集团母公司/上市主体**与**主力研发子公司/海外主体**；
  - 自动生成独立交互式 HTML 看板（含集团公司树折叠、年度/地域图表、代表专利摘要附图缩略图、全屏放大 Lightbox 及官方 PDF 下载按钮）。
- **单篇专利深度精读 (`detail`)**：
  - 一句话看懂核心方案、独立/从属权利要求结构化拆解、说明书关键段落提取；
  - 说明书附图说明与全文高清附图（`fulltext_image`）自动配对画廊；
  - **外文专利自动中外双语对照**：自动识别美/欧/日/韩/WIPO 等非中文专利，提供 **`[🔀 中外对照 | 🇨🇳 仅看中文 | 🌐 仅看原文]`** 一键切换。
- **防冗余双轨输出**：WorkBuddy 聊天框严格控制在 18~22 行以内极简导读卡，全量明细与高清大图由本地 HTML 交互看板承载。

## 🚀 同事如何使用（仅需 1 步）

### 方式一：在 WorkBuddy 中通过 Git 仓库拉取
在 WorkBuddy 的技能（Skills）管理中，直接填入本仓库地址拉取：
```text
https://github.com/Addworldd/zhihuiya-patent-assistant.git
```
或在本地 `skills` 目录下执行：
```bash
git clone https://github.com/Addworldd/zhihuiya-patent-assistant.git
```

### 方式二：下载 ZIP 包直接上传
1. 点击本页面右上角的绿色按钮 **`<> Code`** ➔ **`Download ZIP`**（或直接使用仓库发布包）。
2. 打开 **WorkBuddy** ➔ **技能管理 (Skills)** ➔ **导入/上传技能**，选择下载的压缩包即可。

## 💬 常用对话示例

- **查公司专利全景**：`我想了解工业富联的专利情况`
- **查技术领域格局**：`调查一下智能猫砂盆领域的专利情况`
- **查特定公司+技术点**：`查一下 Eight Sleep 的床垫温度调节专利，重点看水路设计`
- **精读某篇代表专利**：在概览结果后直接回复 `#1` 或 `看 US12250920B2 的详情`
- **自定义分析模板**：回复 `0` 打开完整模块清单自由组合或保存自定义模板
